# 需求文档：小学生学习辅导工作台

> 文档状态：已更新（2026-08-20，新增 F13/F14）。基于 2026-08-19 冻结口径增量迭代，后续改动需同步 DESIGN 与 README。

## 1. 背景与目标

家长需要一个能随孩子年级成长自动适应的小学生学习辅导工作台，而不是一份固定的静态课表。产品参照「伊伊早教工作台」的产品范式，把面向宝宝的“每日模块 + 周主题 + 活动库 + 观察记录”迁移到学龄段：家长首次设置孩子档案后，系统按年级、学期与日期自动生成可落地、可勾选、不施压的每日学习辅导计划。

目标：

- 一次设置就读年级与学期，系统长期跟随成长自动更新内容。
- 每天可直接落地：左侧打勾、右侧滚动浏览全部模块。
- 内容建立在真实书本、文具、生活实物与亲子互动之上，离线可做、不费妈、不超量。
- 数据保存在本机，支持手动导出与导入；在线链接多设备可访问，无需账号与云同步。
- 内容真可用：练习与口语条目可直接照做，无需家长二次加工。
- 假期与学期衔接自然：一年级暑假可预习二年级，开学后可按校内实际进度校准，避免超前或滞后。

## 2. 核心用户与使用场景

- 主用户：家长（安排与陪伴）。
- 使用对象：小学生（6-12 岁，1-6 年级），本期不单独做孩子端。
- 屏幕原则：本工具是“计划和清单”，主要由家长与孩子共同查看，不替代学习本身；学习内容尽量在纸面、书本与生活中完成，不在手机上长时间刷题或上课。
- 典型流程：首次设置年级档案 → 每天打开看今日计划 → 完成一项打勾 → 已完成内容可重复做或筛选新内容手工选择 → 每周主题自动轮换 → 假期开启预习模式 → 开学切换为学期同步并按校内进度校准 → 跨学期或升年级时内容自动升级。

## 3. 非目标（明确不做）

- 不做在线网课、直播课或 AI 实时讲解工具（本期范围外，如需再单独立项）。
- 不做屏幕刷题游戏或依赖手机长期沉浸的学习。
- 不替代学校老师布置作业，也不内置与版权教材冲突的整册题目。
- 不做题海、排名、成绩横向量化或任何施压性呈现。
- 不要求孩子背诵式跟读、不搞超前超量，尊重孩子节奏。
- 不做账号体系与云同步（本期本机存储 + 手动导出导入已满足多设备需求）。
- 不自动对接学校系统获取进度，校准由家长手动标记。

## 4. 功能需求

### F1 学生档案与年级初始化

- 首次使用进入设置页：昵称、当前年级与学期、教材版本（语文/数学/英语，如人教版、北师大版等）、每日可用时段、薄弱科目偏好、是否启用英语与素质模块。
- 新增学段状态：假期预习 / 学期同步；预习目标年级、开学日期（用于预习包起止与开学一键切换）。
- 系统按“年级 + 学期 + 学段状态”映射到对应内容带，支持手动预览下一阶段预告但不改变实际判定；开学一键由预习态切为同步态，暑假记录自动按学期归档。

### F2 年级自适应内容（全年级全学科覆盖）

- 内容按年级与学期组织，跨年级自动切换；假期预习时按“目标年级上学期前 4 单元预热包”组织。
- 覆盖 1-6 年级全部年级与学科（语文、数学、英语、运动健康、素质劳动），每个年级的学科侧重、难度、时长与推荐书单独立配置；不只做 1-2 个年级样例。
- 按上下学期 / 单元细分时，内容可进一步区分，预习条目标注 preview=true。
- 升年级与跨学段切换时保留历史记录并按年级+学期归档，可回看。

### F3 每日固定模块 + 学习观察

每天固定生成并展示以下板块（左侧打勾，右侧上下滚动）：

1. 语文积累：字词、朗读、阅读、表达。
2. 数学思维：口算、生活数学、思维题（低强度）。
3. 英语积累：磨耳朵、跟读、绘本、日常短句（真可用口语与练习）。
4. 运动与健康：跳绳、球类、眼保健操、作息。
5. 素质与劳动（可选开关）：家务、实验、手工、兴趣。
6. 学习观察与养育提醒：专注时长、坐姿、错题整理、情绪状态等当日提醒。

> 各学科条目为可直接使用的练习/口语内容，家长可替换为实际书本页码，系统不再只提供“模板”而是提供“可用内容”。预习态与同步态的模块配额与文案一致，仅内容来源与权重不同。

### F4 每周主题循环系统

- 固定周主题轮换：阅读周、口算周、词汇积累周、表达周、科普实验周、劳动生活周、复盘周等（示例，可按学期调整）。
- 同一主题在不同年级呈现不同难度与玩法，重复且渐进，符合记忆规律。
- 预习期与学期内共用同一周主题轮换，不单独起新循环。

### F5 活动库（学习/互动库）

- 按“年级 × 学科 × 主题”三条件筛选，覆盖 1-6 年级全量；预习期支持按“目标年级 + 预习”标签筛选。
- 学科：语文、数学、英语、阅读表达、运动健康、素质劳动。
- 主题：字词、口算、阅读、口语、科普实验、家务劳动、运动、情绪等。
- 每条活动含：适用年级、适用单元、准备物品、玩法步骤、时长建议与安全提示；预习条目额外含原年级对照。
- 优先使用真实书本、文具、家庭物品与生活场景，实物与纸质操作优于电子内容。

### F6 学习观察记录

- 按年级提供观察项，分为专注力、读写姿势、阅读习惯、作业效率、错题整理、情绪状态等几类（非成绩排名）。
- 打勾自动保存本机，跨年级归档可回看，并按新年级提供新观察项；观察记录按 gradeKey + term 归档。
- 注明“仅作陪伴参考，专业评估以老师与医生为准”。

### F7 学科内容真生成（可用练习/口语）

- 本期明确生成可直接使用的练习与口语内容，而非仅提供框架或建议。
- 语文：生字抄写清单、朗读打卡句段、分级阅读书单与配套练习（不整册搬运版权教材）。
- 数学：口算题卡（可打印）、生活数学任务、低强度思维题，均可直接做。
- 英语：磨耳朵音频清单、跟读音频/文本、日常短句与口语对话，均可直接跟读与播报。
- 口语与练习内容支持浏览器语音播报与本地音频播放。

### F8 内容生产流程（AI 草稿 + 人工审核）

- 覆盖范围：1-6 年级 × 全学科，批量生产；预习包为目标年级上学期前 4 单元的轻量预热版。
- 流程：AI 按年级大纲与学科要求生成草稿 → 人工审核（贴合教材节奏、安全性、时长、可落地性、版权边界）→ 审核通过后入库进入内容池。
- 每个年级 × 每个学科内容池条目数建议 ≥10 条以保证轮换多样性；预习标签池每单元 ≥3 条。
- 未经审核的内容不得进入线上内容池。
- 书单只给建议，不内置受版权保护的整册题目。

### F9 任务完成与内容流转（已完成复用 + 筛选新内容手工选）

- 每个任务支持打勾“已完成”，已完成记录保留在本机，跨日可回看。
- 已完成的内容可重复做（重复打勾或重置后重做），不强制消失。
- 当日计划之外，家长可在活动库中按年级/学科/主题筛选新内容，手工选择加入今日或收藏为常用。
- 系统优先推荐未完成或近期待轮换的内容，但不自动覆盖家长手工选择。
- 已完成与手工选择的记录均纳入归档与导出范围。

### F10 数据与备份

- 打勾、观察记录、学生档案（含学段状态与校准记录）、手工选择记录均保存在本机（localStorage / IndexedDB）。
- 提供导出 JSON 与导入 JSON，换设备时可恢复；导出文件包含年级归档、预习记录与校准历史。
- 无账号体系，无云同步。

### F11 导航与布局

- 左侧纵向导航栏常驻、不收起，彩色图标 + 文字；侧栏宽度适中。
- 右侧一次展示全部模块，上下滚动浏览，不溢出。
- 点击今日模块时展示其子模块，与右侧内容联动。

### F12 部署与多设备

- PWA 单页应用，可添加到手机桌面当 App 使用，支持离线可用。
- 生成可多设备访问的在线链接（静态站点，如 GitHub Pages）；数据仍以本机存储为准，跨设备通过导出导入同步。
- 无需登录即可使用。

### F13 假期预习模式（一升二等跨年级衔接）

- 适用场景：一年级已结课、二年级未开学等假期衔接期，家长开启预习态后系统按“目标年级上学期前 4 单元”生成轻量预习包。
- 时长与节奏：预习包覆盖 6-8 周，每天总量 20-30 分钟，每学科每天 1-2 条，轻量不超量，支持跳过/明日再补。
- 内容形态：预热版（识字与拼音预热、100 以内加减与表内乘法预热、字母与词汇磨耳朵），每条标注 preview=true，玩法偏绘本、口算卡与生活实物。
- 生成规则：同一天、同目标年级、同周主题的预习结果稳定可复现；活动库可按“目标年级 + 预习”筛选并手工替换当日条目。
- 升学期切换：到达开学日期或家长一键切为学期同步，预习记录按学期归档，次日计划即按新学期同步逻辑生成。

### F14 学期进度校准（理论进度与校内实际对齐）

- 能力：开学进入学期同步态后，家长可在档案-校准进度中按学科标记校内实际进度（语文第 X 单元、数学第 X 单元、英语第 X 单元，下拉选单元，不手写）。
- 重排规则（次日生效）：
  - 已教单元：对应内容权重转“巩固/错题/朗读”，难度不提升；
  - 正在教单元：同步练习为主；
  - 未教单元：仅保留轻量预习或不出现，避免超前超量。
- 容差与频率：建议每 1-2 周校准一次，容差 ±1 周；未校准时沿用教材默认单元进度。
- 可追溯：校准记录可回看与撤销，导出导入包含校准历史；同一天同校准结果刷新不跳动。

## 5. 学习原则

1. 固定、可预估的时长，低年级单科 15-20 分钟为宜，不贪多；预习期总量 20-30 分钟/天。
2. 保护专注：完成任务时不频繁打断、不催促、不代劳。
3. 优先实物与纸质，弱化屏幕依赖。
4. 可跳过/明日再补，不施压；不做排名与横向对比。
5. 内容可重复、渐进，符合记忆与成长规律；预习与同步均不超纲。

## 6. 验收框架

- 年级自适应：切换年级后次日计划即更新为新年级内容，旧记录归档可回看。
- 预习衔接：开启预习态（一年级完成→二上预习），次日计划即按目标年级预习包生成且不含旧年级旧内容；活动库可筛选预习条目并手工加入。
- 进度校准：学期同步态校准到第 2 单元后，次日计划中第 1 单元转巩固、第 3 单元不提前；校准记录可撤销；同一天同校准结果刷新不跳动。
- 每日计划：同一天、同一年级、同周主题（同校准进度）生成结果稳定可复现，刷新不跳动。
- 真生成：语文/数学/英语每日条目均为可直接使用的练习/口语，无需家长二次编写。
- 内容覆盖：1-6 年级 × 各学科均有独立内容池且通过人工审核；预习标签池每单元 ≥3 条。
- 任务流转：已完成可重复做；活动库筛选后手工选择可加入今日并持久化。
- 多设备：在线链接在手机/平板/电脑均可访问；本机数据导出后在另一设备导入可完整恢复（含校准历史）。
- 非目标：无网课、无刷题沉浸、无题海排名、无账号云同步、无自动对接学校系统。
