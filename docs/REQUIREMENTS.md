# 需求文档：小学生学习辅导工作台

> 文档状态：待讨论、待冻结。当前阶段只完善需求框架，不进入开发。

## 1. 背景与目标

家长需要一个能随孩子年级成长自动适应的小学生学习辅导工作台，而不是一份固定的静态课表。产品参照「伊伊早教工作台」的产品范式，把面向宝宝的“每日模块 + 周主题 + 活动库 + 观察记录”迁移到学龄段：家长首次设置孩子档案后，系统按年级、学期与日期自动生成可落地、可勾选、不施压的每日学习辅导计划。

目标：

- 一次设置就读年级与学期，系统长期跟随成长自动更新内容。
- 每天可直接落地：左侧打勾、右侧滚动浏览全部模块。
- 内容建立在真实书本、文具、生活实物与亲子互动之上，离线可做、不费妈、不超量。
- 数据保存在本机，支持手动导出与导入。

## 2. 核心用户与使用场景

- 主用户：家长（安排与陪伴）。
- 使用对象：小学生（6-12 岁，1-6 年级）。
- 屏幕原则：本工具是“计划和清单”，主要由家长与孩子共同查看，不替代学习本身；学习内容尽量在纸面、书本与生活中完成，不在手机上长时间刷题或上课。
- 典型流程：首次设置年级档案 → 每天打开看今日计划 → 完成一项打勾 → 每周主题自动轮换 → 跨学期或升年级时内容自动升级。

## 3. 非目标（明确不做）

- 不做在线网课、直播课或 AI 实时讲解工具（本期范围外，如需再单独立项）。
- 不做屏幕刷题游戏或依赖手机长期沉浸的学习。
- 不替代学校老师布置作业，也不内置与版权教材冲突的整册题目。
- 不做题海、排名、成绩横向量化或任何施压性呈现。
- 不要求孩子背诵式跟读、不搞超前超量，尊重孩子节奏。
- 不以登录账号和云同步为默认前提（本期本机为主）。

## 4. 功能需求

### F1 学生档案与年级初始化

- 首次使用进入设置页：昵称、当前年级与学期、教材版本（语文/数学/英语，如人教版、北师大版等）、每日可用时段、薄弱科目偏好、是否启用英语与素质模块。
- 系统按“年级 + 学期”映射到对应年龄带内容，支持手动预览下一阶段预告但不改变实际判定。

### F2 年级自适应内容

- 内容按年级与学期组织，跨年级自动切换。
- 覆盖 1-6 年级，共 6 个年级（可再按上下学期细分），每个年级的学科侧重、难度、时长与推荐书单独立配置。
- 升年级时保留历史记录并按年级归档，可回看。

### F3 每日固定模块 + 学习观察

每天固定生成并展示以下板块（左侧打勾，右侧上下滚动）：

1. 语文积累：字词、朗读、阅读、表达。
2. 数学思维：口算、生活数学、思维题（低强度）。
3. 英语积累：磨耳朵、跟读、绘本、日常短句。
4. 运动与健康：跳绳、球类、眼保健操、作息。
5. 素质与劳动（可选开关）：家务、实验、手工、兴趣。
6. 学习观察与养育提醒：专注时长、坐姿、错题整理、情绪状态等当日提醒。

> 各学科条目依据“当下教材单元 + 学习方法模板”生成，家长可替换为实际书本内容。

### F4 每周主题循环系统

- 固定周主题轮换：阅读周、口算周、词汇积累周、表达周、科普实验周、劳动生活周、复盘周等（示例，可按学期调整）。
- 同一主题在不同年级呈现不同难度与玩法，重复且渐进，符合记忆规律。

### F5 活动库（学习/互动库）

- 按“年级 × 学科 × 主题”三条件筛选。
- 学科：语文、数学、英语、阅读表达、运动健康、素质劳动。
- 主题：字词、口算、阅读、口语、科普实验、家务劳动、运动、情绪等。
- 每条活动含：适用年级、准备物品、玩法步骤、时长建议与安全提示。
- 优先使用真实书本、文具、家庭物品与生活场景，实物与纸质操作优于电子内容。

### F6 学习观察记录

- 按年级提供观察项，分为专注力、读写姿势、阅读习惯、作业效率、错题整理、情绪状态等几类（非成绩排名）。
- 打勾自动保存本机，跨年级归档可回看，并按新年级提供新观察项。
- 注明“仅作陪伴参考，专业评估以老师与医生为准”。

### F7 学科内容模板与书单

- 语文：生字抄写模板、朗读打卡规则、分级阅读书单建议（不内置受版权保护的整册内容）。
- 数学：口算题卡生成规则、生活数学任务、低强度思维题。
- 英语：磨耳朵音频、日常短句、绘本书单建议，语音可播报。
- 提供“家长指定教材页/单元 + 系统生成练习框架”的协作方式，避免年级与教材失配。

### F8 数据与备份

- 打勾、观察记录、学生档案均保存在本机。
- 提供导出 JSON 与导入 JSON，换设备时可恢复。

### F9 导航与布局

- 左侧纵向导航栏常驻、不收起，彩色图标 + 文字；侧栏宽度适中。
- 右侧一次展示全部模块，上下滚动浏览，不溢出。
- 点击今日模块时展示其子模块，与右侧内容联动。

### F10 部署与多设备

- PWA 单页应用，可添加到手机桌面当 App 使用。
- 保留离线可用能力。
- 生成可多设备访问的在线链接；数据同步默认本机 + 手动导出导入。

## 5. 学习原则

1. 固定、可预估的时长，低年级单科 15-20 分钟为宜，不贪多。
2. 保护专注：完成任务时不频繁打断、不催促、不代劳。
3. 优先书本、纸笔、真实生活物品，电子工具只作计划与清单。
4. 内容融入日常，不频繁“上课式”堆砌，保证留白与自由玩耍。
5. 尊重孩子节奏，不强迫展示、不攀比、不超前超量。
6. 每题、每项都给出“可选 / 允许跳过 / 明天再补”的退路，降低压力。
7. 错题与困难做复盘而非批评，培养自主与韧性。

## 6. 验收标准

- 首次设置年级后，今日计划随年级与日期自动更新，无需人工编辑。
- 6 个年级各有独立且可落地的学科内容、书单、观察项与时长模板。
- 每个年级每日固定模块 + 学习观察可全部显示并上下滚动，左侧可勾选。
- 勾选与观察记录刷新后保留，导出导入可恢复。
- 升年级后旧记录归档可回看，新内容自动启用。
- 移动端可添加到主屏幕，英语短句可语音播报。
- 部署后生成多设备可访问的在线链接。
